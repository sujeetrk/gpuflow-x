# GPUFlow-X

## AI-Driven Self-Learning GPU Inference Scheduler

GPUFlow-X is an experimental GPU inference scheduling platform designed to dynamically optimize request batching, queue delay, scheduling policy, and GPU resource utilization under configurable latency and memory constraints.

The system combines high-performance C++ scheduling, GPU acceleration, machine learning-based workload prediction, and a self-learning scheduling policy.
